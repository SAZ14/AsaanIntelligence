# Loans agent data

## `loans_pakistan_finetune_10k.jsonl`

10,000 synthetic chat-format training examples for the loans agent's local
model. Each line: `{"messages": [user, assistant], "meta": {task, lang, source}}`.

- **Languages**: 50% English, 50% Roman Urdu
- **17 task types** (~588 each): `relationship_scoring`, `proactive_offer_decision`,
  `low_cash_detection`, `portfolio_triage`, `decline_with_alternatives`,
  `dbr_calculation`, `emi_calculation`, `max_affordable_loan`,
  `loan_offer_comparison`, `early_settlement_analysis`, `delinquency_risk_grading`,
  `gold_loan_sizing`, `ecib_report_reading`, `restructuring_assessment`,
  `topup_eligibility`, `salary_advance_assessment`, `product_recommendation`
- Some assistant turns contain `<think>…</think>` scratchpads (the agent strips
  them before display).

The embedded lending policy (relationship scoring bands, the 10-day
under-Rs 5,000 stress marker, 40% DBR cap, no unsecured offers to POOR files)
is implemented deterministically in `app/agents/loans/policy.py` — the model
is only ever the narrator.

## `fewshot.jsonl`

One curated English example per task type (17 rows), used as few-shot context
for the *base* local model before fine-tuning. After fine-tuning, set
`LOAN_FEWSHOT=0`.

## `customer_book.json`

Seeded synthetic demo customer base (60 profiles) generated by
`scripts/generate_loan_book.py`. Regenerate or resize:

```bash
python scripts/generate_loan_book.py --n 100 --seed 47
```
